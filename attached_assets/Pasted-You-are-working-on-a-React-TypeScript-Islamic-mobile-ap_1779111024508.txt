## 1. Translation Service — src/lib/translationService.ts

Create a real translation service using the LibreTranslate public API 
(https://libretranslate.com) with fallback to MyMemory API 
(https://api.mymemory.translated.net) if LibreTranslate fails.

The service must:
- translateText(text: string, targetLang: string): Promise<string>
  → Translates a single string from Arabic ("ar") to target language
  → Try LibreTranslate first, fallback to MyMemory
  → Return original Arabic text if both APIs fail

- translateBatch(texts: string[], targetLang: string): Promise<string[]>
  → Translate an array of strings efficiently (batch or Promise.all with 
    concurrency limit of 3 to avoid rate limits)
  → Return original texts as fallback on error

- Cache results in localStorage with key format:
  "tr_cache_{lang}_{hash}" where hash = btoa(text).slice(0,16)
  → On cache hit, return instantly without API call
  → Cache is persistent across sessions

- Supported target languages: en, fr, es, tr, id
  (Arabic "ar" = no translation needed, return as-is)

- Export: { translateText, translateBatch, clearCache }

## 3. Translation Hook — src/hooks/useContentTranslation.ts

Create a custom hook:

useContentTranslation(items: ContentItem[], language: string)

Returns:
{
  translatedItems: Array<ContentItem & { translatedText: string }>,
  isTranslating: boolean,
  translationProgress: number  // 0–100
}

Behavior:
- If language === "ar": translatedText = arabic (no API call)
- If language !== "ar": 
  → Check cache for each item first
  → Batch-translate only uncached items
  → Show isTranslating = true and update progress during translation
  → Merge cached + freshly translated results
  → On complete, isTranslating = false
